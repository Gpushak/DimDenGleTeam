# Warehouse Server

Backend для АСУ складского учёта: REST API на **FastAPI** с базой данных **SQLite**.

Управляет типами коробок, иерархией коробок (дерево вложенности), типами предметов и предметами внутри коробок.

## Технологии

- Python 3.12
- FastAPI + Uvicorn
- SQLite (файл БД, без внешнего сервера БД)
- Docker / Docker Compose

## Структура проекта

```
warehouse-server/
├── app/
│   ├── main.py            # Точка входа FastAPI, инициализация БД
│   ├── database.py        # Подключение к SQLite (get_db)
│   └── routers/
│       ├── box_types.py   # CRUD типов коробок
│       ├── boxes.py       # Коробки: дерево, содержимое, перемещение
│       ├── item_types.py  # CRUD типов предметов
│       └── items.py       # Предметы: учёт количества, размещение в коробках
├── db/
│   └── schema.sql         # Схема БД (таблицы, индексы, триггеры)
├── data/
│   └── warehouse.db       # Файл базы данных SQLite (создаётся автоматически)
├── Dockerfile
└── requirements.txt
```

## Быстрый старт

### Через единый docker-compose (рекомендуется)

Из корня репозитория:

```bash
docker compose up --build
```

Сервер будет доступен на `http://localhost:8000`. Данные БД хранятся в named-volume `warehouse-data` (путь в контейнере задаётся переменной `WAREHOUSE_DB`, по умолчанию `/data/warehouse.db`), схема монтируется из `./server/db`.

### Локально

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

При первом запуске база `data/warehouse.db` создаётся автоматически из `db/schema.sql`.

## Эндпоинты

### Типы коробок (`/box-types`)

| Метод  | Путь                  | Описание             |
|--------|-----------------------|----------------------|
| GET    | `/box-types`          | Список типов коробок |
| GET    | `/box-types/{id}`     | Тип коробки по ID    |
| POST   | `/box-types`          | Создать тип (`{"name": "..."}`) |
| DELETE | `/box-types/{id}`     | Удалить тип (409, если используется) |

### Типы предметов (`/item-types`)

| Метод  | Путь                    | Описание               |
|--------|-------------------------|------------------------|
| GET    | `/item-types`           | Список типов предметов |
| GET    | `/item-types/{id}`      | Тип предмета по ID     |
| POST   | `/item-types`           | Создать тип (`{"name": "...", "weight_g": 100}`) |
| DELETE | `/item-types/{id}`      | Удалить тип (409, если используется) |

### Коробки (`/boxes`)

| Метод  | Путь                        | Описание                                        |
|--------|-----------------------------|--------------------------------------------------|
| GET    | `/boxes`                    | Список всех коробок                              |
| GET    | `/boxes/tree`               | Дерево коробок (вложенная иерархия)              |
| GET    | `/boxes/{id}`               | Коробка по ID                                    |
| GET    | `/boxes/{id}/children`      | Непосредственные вложенные коробки               |
| GET    | `/boxes/{id}/contents`      | Содержимое коробки (предметы + вес)              |
| POST   | `/boxes`                    | Создать коробку (`{"name", "box_type_id", "parent_id?"}`) |
| PATCH  | `/boxes/{id}`               | Изменить имя / тип коробки                       |
| POST   | `/boxes/{id}/move`          | Переместить коробку (`{"parent_id": ... \| null}` — null = корень) |
| DELETE | `/boxes/{id}`               | Удалить коробку (каскадно удаляет вложенные)     |

### Предметы (`/items`)

| Метод  | Путь              | Описание                                                     |
|--------|-------------------|---------------------------------------------------------------|
| GET    | `/items`          | Список предметов (фильтр `?box_id=`)                          |
| GET    | `/items/{id}`     | Предмет по ID                                                 |
| POST   | `/items`          | Добавить предмет (`{"item_type_id", "box_id?", "quantity"}`)  |
| PATCH  | `/items/{id}`     | Изменить количество или переместить в другую коробку          |
| DELETE | `/items/{id}`     | Удалить запись о предмете                                     |

## Модель данных

- **box_type** — справочник типов коробок (уникальное имя).
- **box** — коробка: имя, тип, необязательный `parent_id` (дерево вложенности). Ограничения:
  - цикл в дереве запрещён (проверяется триггером `trg_box_no_cycle`);
  - коробка не может быть своим собственным родителем;
  - имена уникальны среди одноуровневых соседей (и среди корневых коробок).
- **item_type** — тип предмета с необязательным весом одного экземпляра `weight_g` (в граммах).
- **item** — количество предметов определённого типа в коробке; `box_id` может быть `NULL` (предмет вне коробки). На одну пару «коробка + тип предмета» — одна запись.

## Примеры запросов

```bash
# Создать тип коробки и коробку
curl -X POST http://localhost:8000/box-types -H 'Content-Type: application/json' -d '{"name": "Ящик"}'
curl -X POST http://localhost:8000/boxes -H 'Content-Type: application/json' -d '{"name": "Стеллаж A", "box_type_id": 1}'

# Создать тип предмета и положить 5 штук в коробку 1
curl -X POST http://localhost:8000/item-types -H 'Content-Type: application/json' -d '{"name": "Гвозди 100мм", "weight_g": 5}'
curl -X POST http://localhost:8000/items -H 'Content-Type: application/json' -d '{"item_type_id": 1, "box_id": 1, "quantity": 5}'

# Посмотреть дерево коробок и содержимое коробки 1
curl http://localhost:8000/boxes/tree
curl http://localhost:8000/boxes/1/contents
```
