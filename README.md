Тема проекта

«АСУ складского учёта с весовым модулем и QR-идентификацией»
Задачи

    Сборка и программирование весового модуля на Arduino

        тензодатчик и HX711 (GPIO);

        передача данных о весе на Linux-ПК через Serial-порт.

    Разработка десктопного приложения на Linux

        генерация QR-кодов для товаров;

        печать этикеток;

        управление справочником товаров.

    Построение REST API на FastAPI

        связь между весовым модулем, десктопом и мобильным приложением;

        хранение данных в SQLite.

    Создание Android-приложения

        создание и управление списками товаров;

        добавление и удаление позиций путём сканирования QR-кодов;

        синхронизация с сервером.

Ожидаемый результат

Работающий прототип системы, позволяющий:

    администратору — генерировать QR-этикетки на ПК;

    кладовщику — взвешивать товары и управлять списками через мобильное приложение;

    получить задокументированный API (Swagger);

    подготовить отчёт о тестировании.
