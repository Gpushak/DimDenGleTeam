# Складской учёт — Python Desktop App

Десктопное приложение для складского учёта с иерархическим хранением контейнеров и товаров.

## Стек

- **Python 3.11+**
- **GUI**: customtkinter (современный интерфейс с тёмной темой)
- **БД**: SQLite через SQLAlchemy 2.0+
- **Архитектура**: пакет с модулями

## Схема БД

```
box_type
├── box_type_id (INTEGER, PK)
└── box_type_name (TEXT, NOT NULL, UNIQUE)

box
├── box_id (INTEGER, PK)
├── box_name (TEXT, NOT NULL)
├── box_type_id (INTEGER, FK → box_type)
└── parent_id (INTEGER, FK → box, nullable)

item_type
├── item_type_id (INTEGER, PK)
├── item_type_name (TEXT, NOT NULL, UNIQUE)
└── weight_g (INTEGER, nullable)

item
├── item_id (INTEGER, PK)
├── item_type_id (INTEGER, FK → item_type)
├── box_id (INTEGER, FK → box, nullable)
├── quantity (INTEGER, NOT NULL, DEFAULT 1)
└── date (TEXT, NOT NULL, DEFAULT datetime('now'))
```

## Установка и запуск

### 1. Установить зависимости

```bash
cd python_app
pip install -r requirements.txt
```

Зависимости:
- SQLAlchemy>=2.0
- customtkinter>=5.2.0

### 2. Запустить приложение

```bash
python main.py
```

При первом запуске будет создан файл `warehouse.db` с демо-данными.

### Особенности customtkinter

- Современный дизайн с тёмной темой по умолчанию
- Плавные анимации и скруглённые элементы
- Адаптивный интерфейс
- Поддержка светлой и тёмной тем

## Функциональность

### Управление контейнерами (дерево слева)
- Добавление контейнеров с выбором типа и родителя
- Редактирование (включая смену родителя)
- Удаление с каскадным удалением потомков (товары остаются с `box_id=NULL`)
- Иерархическое отображение структуры склада

### Управление товарами (таблица справа)
- Создание товаров с выбором типа, контейнера и количества
- Редактирование и удаление
- Отображение типа, количества, веса, даты, расположения

### Типы товаров
- Создание типов товаров с указанием веса
- Вес используется для расчёта общего веса товаров

### Поиск
- Поиск по названию типа товара
- Поиск по расположению

### Разделы
- **Все товары** — все записи в БД
- **Без расположения** — товары с `box_id=NULL`
- Конкретный контейнер — товары в контейнере и всех потомках

## Демо-данные

При первом запуске создаются:
- 8 типов контейнеров (Склад, Стеллаж, Полка, Ячейка, Зона, Помещение, Контейнер, Коробка)
- 10 контейнеров в иерархии
- 8 типов товаров (болты, гайки, шайбы, краска, кисти, масла и т.д.)
- 8 записей товаров

## Удаление БД

Чтобы пересоздать базу с демо-данными:

```bash
rm warehouse.db
python main.py
```
