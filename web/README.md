# Веб-приложение складского учёта

Браузерный клиент с тем же функционалом, что `desktop/`: дерево контейнеров,
таблица товаров, типы, QR-этикетки `qwentory:item:<id>`, показания весов и
смена адреса сервера. Своей базы нет — данные только на Warehouse API.

## Стек

- Vue 3, TypeScript, Pinia, SCSS
- Vite

## Запуск

API должен быть доступен по адресу общего сервера (как у десктопа). Локальный
`127.0.0.1` / `localhost` клиент не принимает.

```bash
cd web
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`. Адрес API по умолчанию —
`http://warehouse-server.tail96180b.ts.net:8000`. Его можно сменить на экране
подключения или кнопкой «Сервер»; выбор сохраняется в браузере.

Переменная `VITE_API_BASE_URL` задаёт адрес, если в браузере ещё ничего не
сохранено.

Сборка:

```bash
npm run build
npm run preview
```
